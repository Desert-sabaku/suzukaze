# 関節位置の手動ラベル付け

`gesture_detection/` から実行します。カメラや推論モデルは使用しません。
OpenCVのウィンドウを開くため、画面のあるデスクトップ環境が必要です。

```bash
uv run python -m scripts.annotate_landmarks sample_movies/打ち水btn.mp4
```

最初に動画を全走査し、先頭と末尾を含めて均等に8フレームを抽出します。
`--count 10` で枚数を変更できます。全走査には動画の長さに応じた時間がかかります。
所作の場面に合わせて選ぶ場合は、0始まりのフレーム番号を指定してください。

```bash
uv run python -m scripts.annotate_landmarks sample_movies/打ち水btn.mp4 --frames 0 30 60 90 120 --output output/annotations/uchimizu-selected
```

出力先の既定値はプロジェクト内の `output/annotations/<動画名（拡張子なし）>/` です。
`--output` で別の新しいディレクトリも指定できます。既存セッションの上書きは拒否します。
抽出だけ行う場合は `--extract-only` を付けます。抽出画像はPNGなので、以降の
作業は元動画がなくても再開できます。

```bash
uv run python -m scripts.annotate_landmarks --resume output/annotations/打ち水btn
```

## 操作

画面下に現在のフレーム・時刻・入力対象が表示されます。左肩、右肩、左手首、
右手首、左股関節、右股関節の順にクリックします。左右は被写体本人の左右です。
肩は肩関節付近、手首は手と前腕の境目、hipは左右の股関節付近を指定します。
モデルの推定点は表示されません。

| 操作 | 内容 |
| --- | --- |
| 左クリック | 現在の点を指定・修正して次の点へ進む |
| U | 判別困難として記録し、次の点へ進む |
| 1〜6 | 同じフレーム内の点を選択して修正 |
| C | 選択中の点を未入力に戻す |
| Z | ひとつ前の点に戻る。置き直すかCで消す |
| N / P | 次／前のフレームへ移動 |
| Q / Esc / ウィンドウを閉じる | 終了 |

6点目を入力したらNで次のフレームへ進みます。入力途中でも移動できます。
各編集で自動保存するため、終了前の保存操作は不要です。再開時は最初の未入力点へ
移動し、全点入力済みなら先頭を表示します。画面下のpending pointsが0になれば
全点に印または「不明」が付いています。

表示は最大1280×720に縮小しますが、保存座標は元画像のピクセル座標です。
必要なら `--max-width 1920 --max-height 1080` などで拡大してください。
座標原点は画像左上、xは右向き、yは下向きです。

## 保存形式と確認

- `frame_000090.png`：元解像度の確認画像。
- `source.json`：動画の絶対パス・SHA-256・抽出フレーム番号など。
- `annotations.csv`：動画名、フレーム番号、時刻（秒）、点名、x/y座標、状態。

状態は `marked`（指定済み）、`uncertain`（不明）、`pending`（未入力）です。
不明と未入力の座標は空欄です。保存時は一時ファイルから置換します。同一セッションを
複数のウィンドウで同時編集しないでください。

画像を見ても判別できない点は無理に推測せずUで飛ばします。人が置いた点も厳密な
真値ではないため、同じ位置基準を用い、必要なら別の人にも確認してもらいます。
同じCSVと画像をLite／Full／ぼかし条件すべてに使用してください。
失敗例だけを選ぶと評価が偏るため、追加の失敗例は別セッションとして記録します。

`output/` はGit管理対象外です。注釈データを共有・保管する際はセッションの
ディレクトリ全体をコピーしてください。
