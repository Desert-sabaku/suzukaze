# 幕越しYOLO Poseの追跡・短時間補間（2026-09-19）

人物矩形の重なりによる追跡、短時間補間、平滑化を既存の網越し動画で比較した。
**扇ぎのランドマーク認識は未解決。誤った骨格を平滑化する場合があり、ジェスチャー判定へ統合できる品質ではない。**

## 方法

- YOLOv8n-pose、CPU、入力640、検出confidence 0.05。画面面積8%以上の矩形を候補とする。
- 最初は最大面積、その後は前回矩形とのIoU最大（0.3以上）を選択。0.25秒未検出なら再取得する。
- 鼻、両肩、両手首、両腰の7点についてconfidence > 0.5かつ画面内の有限座標を実検出として保存する。
- 同じ追跡区間内で、両端の実検出の時間差が0.15秒以内の場合だけ線形補間。端の欠落・長い欠落は埋めない。
- 補間後に時定数0.05秒のEMAを適用。欠落や追跡区間変更では平滑化をリセットする。
- 元検出・追跡後・補間後・平滑化後と補間点フラグを個別保存する。

補間は未来のフレームを必要とするオフライン処理である。リアルタイム化には最大0.15秒程度の待ち時間が必要。
モデルの信頼度と座標の正しさは同一ではなく、以下は認識精度ではなく7点の利用可能率である。
画面外座標を除外したため、前回のconfidenceだけの集計とは直接比較できない。

## 観察

全動画の全フレームで比較した7点の利用可能率（補間後は推定点を含む）：

| 動画 | 元検出 | 追跡後の実検出 | 短時間補間後 | 追跡区間数 |
| --- | ---: | ---: | ---: | ---: |
| ラムネ | 83.2% | 81.9% | 90.9% | 1 |
| 夕涼み | 17.6% | 17.6% | 23.8% | 1 |
| 扇ぎ | 36.4% | 24.6% | 34.9% | 11 |
| 打ち水 | 34.4% | 29.9% | 33.6% | 7 |

元検出と追跡後で採用フレームが異なるため、座標差の低下には選別の影響もある。
追跡は対応しない矩形を棄却する分、利用可能率を下げる。補間はその一部を埋めるが、
扇ぎ・打ち水では元検出の率さえ超えなかった。
集計の全データは [pose-temporal.json](pose-temporal.json) に保存した。
打ち水は最初の実行が終了コード143で中断したため単独再実行し、
軌跡と代表画像は `output/pose-temporal-uchimizu/` に保存している。

扇ぎの代表12フレームを確認すると、約4.9〜5.9秒では実演者に沿った点が出る一方、
他の時刻では片腕や胴体の一部を別の人体として推定している。
面積8%以上という条件だけで実演者の骨格を保証できるという以前の説明は強すぎた。
追跡後も誤った骨格が残り、補間がそれを連続させる場合がある。

また、以前の「座標の揺れが約20倍」という説明は、動作速度・低信頼点・人物切替が混じる
座標差から導いたものだった。純粋な推定誤差の倍率ではない。
今回は信頼できる隣接点だけの座標差を記録するが、それでも実際の動作を含む。
平滑化でこの値が下がること自体を精度改善とは扱わない。

## 再現

```bash
PYTHONPATH=. uv run python -m scripts.evaluate_pose_temporal --model /tmp/yolov8n-pose.pt
```

モデルファイルのパスは取得先に合わせる。出力は `output/pose-temporal/` の
`report.json` と動画ごとの `.npz`、代表フレーム画像。モデル・動画は別途必要。
今回確認した扇ぎ画像は `output/pose-temporal/fanning-review.jpg`。

## 結論

短い欠落への補間は一部有効だが、誤った人体形状や長い欠落を解決しない。
次の比較では、実演者の肩・手首・腰を代表フレームに手動注釈し、
骨格の位置誤差で別の姿勢モデルや撮影条件を評価する必要がある。
この試作によるランドマーク認識解決やジェスチャー精度向上は確認していない。

欠落補間・人物対応の境界条件を検証する3テスト、ruff、型検査を通過した。
