# 幕越し姿勢認識の追試（2026-09-19）

## 結論

confidence低下、縮小、CLAHE、中央マスク、YOLOによる切り抜きのいずれも、扇ぎ・夕涼み・
ラムネを解決しませんでした。全体前処理は採用せず、MediaPipeのconfidenceは`0.50`を維持
します。YOLO Poseの時系列処理も後続評価で品質不足と判明したため、製品へ統合しません。
次は手動注釈した関節位置または動作区間で、撮影条件とモデルを評価する必要があります。

MediaPipe条件の詳細は [curtain-comparison.json](curtain-comparison.json)、YOLOの生データは
[幕越し](yolo-pose-curtain.json)と[通常撮影の対照](yolo-pose-control.json)です。

## MediaPipe 条件比較

4本の `*btn.mp4` を使いました。ラムネ動画は現行仕様の動作ですが、理想的な実演とは
限りません。打ち水の期待区間は16〜23秒の中断を除き、他は全区間です。

| Fullモデルの条件 | 扇ぎの姿勢あり | 夕涼みの姿勢 / 重要点 | 打ち水の期待 / 他動作 | ラムネ |
| --- | ---: | ---: | ---: | ---: |
| 基準 confidence 0.50 | 0.0% | 44.3% / 36.5% | 28/695 (4.0%) / 22 | 0 |
| 検出・存在 0.35 | 0.0% | 93.8% / 47.1% | 45/695 (6.5%) / 45 | 0 |
| 検出・存在 0.20 | 1.9% | 80.8% / 51.1% | 31/695 (4.5%) / 27 | 0 |
| 面積50%へ縮小 | 0.0% | 91.3% / 4.0% | 11/695 (1.6%) / 69 | 0 |
| 中央マスク＋縮小 | 0.3% | 89.5% / 0.0% | 1/695 (0.1%) / 31 | 0 |

CLAHE、縮小＋CLAHE、縮小なし中央マスクは扇ぎ動画で姿勢を1フレームも検出しませんでした。
0.35は夕涼みの姿勢検出を増やし、打ち水もわずかに増やしましたが、打ち水区間の他動作も
約2倍になり、動作単位の正味改善を示せませんでした。

## YOLO Pose 比較

YOLOv8n-poseを入力640、confidence 0.05で評価しました。低confidenceでは背景人物も拾う
ため、画面面積8%以上の矩形だけを実演者候補とした、この撮影環境専用の集計です。

| 動画 | 実演者姿勢 | 重要点すべて > 0.5 | 点confidence平均 | 点移動量p95 |
| --- | ---: | ---: | ---: | ---: |
| ラムネ | 100.0% | 85.1% | 0.846 | 0.066 |
| 夕涼み | 100.0% | 33.7% | 0.706 | 0.067 |
| 扇ぎ | 81.0% | 36.4% | 0.743 | 0.406 |
| 打ち水 | 90.7% | 36.1% | 0.716 | 0.167 |

通常カメラの対照動画は全て姿勢あり100%、重要点94.5〜98.5%、移動量p95は
0.010〜0.020でした。幕によって、人物が検出できても関節点の欠落と不安定さが増えています。
YOLOの人物矩形で切り抜いてMediaPipe Fullへ渡す試作も、扇ぎ321フレーム中260フレームで
矩形を得ながら、重要点が揃うフレームも動作出力もゼロでした。

## ラムネ失敗の診断

MediaPipe Fullは必要な両肩・両手首・両腰を306/309フレームで検出しました。しかし準備
条件を満たしたのは11区間・計16フレームで、最長0.068秒と必要な0.25秒に届きませんでした。
状態は `IDLE` 293フレーム、`FORMING` 16フレーム、`READY` 0フレームです。

検出された手の上下間隔中央値は肩幅の0.174で、設定下限0.30を下回りました。横方向の
整列中央値は0.570で上限0.60に近い値でした。この動画は現行仕様の失敗例として保存しますが、
単一かつ不完全な可能性のある実演だけを根拠に本番しきい値は緩めません。
