# 幕越し精度の最終検証手順

## 目的

幕越し入力に対する具体的な運用操作を決め、同じ人物・同じ所作の幕なし入力と比較して、
動作検出率と誤発火率が同程度であることを実証する。

現在の1名・各3本では方式候補の除外と予備的な改善確認はできるが、1本の差が33ポイントに
なる。最終判断では各条件・各動作を少なくとも10試行撮影する。

## 比較する入力条件

同じ服装、立ち位置、カメラ位置、画角、照明で、各動作を次の順に撮影する。

1. `without`: 幕なし基準
2. `curtain_raw`: 現在の幕越し入力
3. `curtain_calibrated`: 開始前の空幕5秒を使った背景マスク
4. `camera_user_side`: カメラを利用者側へ移し、幕を通さず撮影できる場合の構成

`camera_user_side`が設置上可能なら、既存姿勢モデルへ分布外の幕画像を入れないため最も確実な
候補である。設置不能なら`curtain_calibrated`を主候補とする。

## 1試行の撮影手順

1. 人物が画角外にいる状態を5秒撮影する。
2. 合図音または画面表示を記録する。
3. 人物が所定位置へ入り、2秒待つ。
4. 指定動作を1回行う。扇ぎと夕涼みは5秒以上継続する。
5. 動作終了後2秒待ち、人物が退出する。
6. 動作開始・完了時刻をその場で記録する。

幕あり・幕なしを別日にまとめ撮りせず、同じ動作の条件を連続して撮る。可能ならカメラ以外を
動かさず、条件順を試行ごとに入れ替える。

## 動作別の候補条件

| 動作 | 幕越し候補 | 現データでの結果 |
|---|---|---|
| 扇ぎ | 空幕背景マスク、MediaPipe Lite、検出・存在0.20 | 幕なし2/3、幕越し2/3 |
| 打ち水 | 空幕背景マスク、MediaPipe Lite、検出・存在0.35 | 幕なし1/3、幕越し1/3 |
| 夕涼み | 空幕背景マスク0.20、肩・腰EMA、速度0.50、ドリフト0.10、1秒 | 幕なし3/3、幕越し2/3 |
| ラムネ | 手のランドマークまたは動作仕様変更 | Pose手首方式では両環境とも0/3 |

動作別条件はUnityが現在の体験シーンを通知し、そのシーンで期待される判定だけを有効化する
前提とする。全条件を常時併用すると、低閾値の打ち水誤発火や、他動作中の静止判定が増える。

## ラムネの追加計測

Poseの手首点では、掌が接触しても手首間隔が約0.6肩幅残る。次回は左右の掌中心、親指、
人差し指の手動注釈を動作前・押下開始・押下完了へ付ける。次のいずれかを比較する。

- MediaPipe Hand Landmarkerなどの手専用モデル
- ラムネ瓶または押し具を画像マーカーとして追跡
- Unityの案内に合わせ、両手を上下に構え一定時間保持する、視覚的に判定可能な所作へ変更
- 物理ボタンや別センサーで開栓完了を入力

準備姿勢だけをPoseで検出する試作は幕なし2/3だったが、幕越しでは正解区間外にも成立したため、
開栓完了の代替にはしない。

## 合格基準

各動作・各条件について以下を集計する。

- 動画単位再現率: 正解区間内に1回以上成立した動画の割合
- 区間外誤発火率: 正解区間外で動作状態になった評価フレームの割合
- 検出遅延: 正解区間開始から最初の成立まで
- 姿勢取得率
- 手動注釈フレームのPCK@0.2。未検出点も失敗に含める

候補を採用する条件は次のすべてを満たすこととする。

1. 幕越し動画単位再現率が幕なしとの差10ポイント以内
2. 幕越し区間外誤発火率が幕なしとの差5ポイント以内
3. 各動作10試行中8試行以上で成立
4. ラムネのような一回性動作は、完了前に通知しない
5. 同じ試行を再実行して結果が変わらない

## 実行コマンド

動画名を`[動作名][通し番号]_[開始秒]-[終了秒].mp4`にそろえ、既存の区間評価器を使う。

```bash
uv run python -m scripts.evaluate_action_intervals \
  --video-root shared/videos \
  --output shared/results/action-intervals-final.json

uv run python -m scripts.evaluate_landmark_annotations \
  --annotations shared/annotations \
  --output shared/results/landmarks-final.json
```

撮影条件はファイル名だけに埋め込まず、条件、人物、試行番号、カメラ設定、照明、幕、モデルと
閾値を結果JSONまたは付随メタデータへ残す。
