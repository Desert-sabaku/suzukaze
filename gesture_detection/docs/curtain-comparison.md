# 幕越し姿勢モデル比較（2026-09-18）

## 結論

Fullモデルは打ち水動画で3条件中もっとも良好でしたが、Lite、Full、Lite＋弱いぼかしの
どれも4動作すべてを認識できませんでした。弱いぼかしは人物姿勢の検出数を増やしても、
重要点や最終判定を安定して改善せず、扇ぎの誤出力も増やしたため、全体適用しません。
正解区間がないので、期待動作のフレーム比率は正解率・再現率・F1値ではありません。

詳細な生データは [curtain-comparison.json](curtain-comparison.json) です。

重要点は鼻、両肩、両手首、両腰の可視度がすべて0.5を超える状態で、分母には姿勢が
見つからないフレームも含みます。Fullは打ち水の期待出力を11から61へ増やし、扇ぎ誤出力を
151から32へ減らしました。一方、ぼかしは全体の姿勢ありを50.9%から80.0%へ増やしても、
重要点は19.1%から23.8%への増加に留まりました。

扇ぎは全条件で人物姿勢の初期検出に失敗しています。ラムネは姿勢を全フレームで検出し、
Fullで重要点も99.0%見えていますが成立しないため、人物検出ではなく関節配置または動作規則
の問題です。夕涼みは7点より多くの全身点を使うため、部分的な改善では成立しませんでした。

## 方法と再現

- Python 3.12.3、MediaPipe 0.10.35、OpenCV 5.0.0、VIDEOモード
- Lite SHA-256: `59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a`
- Full SHA-256: `5134a3aad27a58b93da0088d431f366da362b44e3ccfbe3462b3827a839011b1`
- 弱いぼかし: Gaussian 5×5、sigma 1.2
- 1920×1080の4動画を条件ごとに新しい解析器で逐次処理

モデルと対象動画を既定位置へ置き、次を実行します。

```bash
uv run python -m scripts.evaluate_curtain
```

計時値は再現記録であり、反復したベンチマークではありません。次の追試は
[幕越し姿勢認識の追試](curtain-followup.md)を参照してください。
