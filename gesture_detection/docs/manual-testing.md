# 手動テスト

自動テストは合成ランドマークと模擬推論を使います。カメラ、利用者、設置条件による認識
品質は、この項目に沿って別途確認してください。結果には入力、モデル、設定値、実行日を
記録します。

## 基本動作

- カメラ入力で起動し、表示、骨格、状態表示を確認する。
- `Esc` とウィンドウの閉じる操作で正常終了する。
- 動画入力で終端まで処理し、最終フレームを含む無音の注釈付き動画が保存される。
- 相対・絶対の入出力パスと、明示した `VIDEO_OUTPUT_PATH` を確認する。

## 夕涼み

- 全身を画面内に入れ、1秒静止した後に成立する。
- 腰、足、腕のいずれか1部位だけを動かしても最初の処理フレームで解除する。
- ゆっくり移動し続けても固定基準からの変位で解除する。
- 小さなランドマーク揺れでは成立を維持する。
- 身体の一部を隠す、画面外へ出す、カメラを動かす各場合に誤って静止扱いしない。

## 打ち水

- 左右それぞれで、低い位置からすくい、短く止め、下げる動作が成立する。
- 横方向へ放す動きを加えても成立する。
- 持ち上げだけ、下げだけ、顔や胸の高さでの扇ぎは成立しない。
- 準備中に手首を隠すと状態を破棄する。
- 成功時に扇ぎへ切り替わらず、その後の意図的な扇ぎは成立する。

## 扇ぎ

- 胴体中央付近で連続して扇ぐと表示が安定する。
- 手を下げて静止すると表示が解除される。
- 胴体中央より少し下への短い逸脱では継続し、深く下げるか長く留めると解除する。
- 打ち水を1回行っただけでは扇ぎへ切り替わらない。
- 打ち水に似た始動から継続的に扇いだ場合は、複数往復後に扇ぎへ切り替わる。

## ラムネ開栓

- 左右の手の役割を入れ替えて成立する。
- 開栓後に上の手を離し、準備をやり直すと再度成立する。
- 両手を一緒に下げる、横に動かす、準備なしで近づける各動作は成立しない。
- 準備中に必要なランドマークを隠すと状態を破棄する。
- ラムネ姿勢の外では扇ぎと打ち水が通常どおり成立する。
- 画面下部の案内が準備、押下、成功、再試行の状態に対応する。

## IMAGE / VIDEO 比較

同じ動画を別プロセスで実行し、出力先を分けます。

```bash
POSE_RUNNING_MODE=IMAGE VIDEO_SOURCE=sample_movies/sample.mp4 VIDEO_OUTPUT_PATH=output/image.mp4 uv run gesture-detection
POSE_RUNNING_MODE=VIDEO VIDEO_SOURCE=sample_movies/sample.mp4 VIDEO_OUTPUT_PATH=output/video.mp4 uv run gesture-detection
```

モデル、しきい値、FPS、入力、実行機を揃え、処理時間と入力動画時間を分けて記録します。
正解区間をフレーム単位で付与したうえで、成立・解除時刻、見逃し、誤検出、追跡欠落後の
復帰を比較します。動作の出力フレーム数だけを認識精度として扱わないでください。
