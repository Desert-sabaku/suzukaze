# 0924 開栓判定の相対位置・動きの特徴量比較

2026-09-26。現ブランチで実施。保存済み骨格を使ってphase分類器を再学習し、action予測・後処理・元注釈・本番コードは変更していない。

## 結論

**手首と肩の相対位置を追加する条件を、次の検証候補とする。** 幕越しの開栓検出は5/7件から6/7件へ増え、再出現0件を維持し、注釈と対応しない出力は1区間から0区間へ減った。幕なしは1/2件を維持した。1フレーム遅れていたramune2を注釈区間内で検出できた。

過去0.1秒・0.2秒の速度まで追加した条件は、幕なしの検出を1/2件から0/2件へ悪化させたため採用しない。特徴量を増やせば必ず良くなる結果ではなかった。

相対位置の追加でもboth2幕越しとramune幕なしは見逃しており、連続実動画の検証も未達。既存データを繰り返し検討した探索結果であり、本番採用・未知データでの精度保証ではない。

## 比較方法

### 入力と特徴量

中央マスク付きの既存Poseキャッシュを使用。`cache_only=True` により、キャッシュや環境マニフェストが欠けた場合は停止し、骨格の再抽出は行わない。

| 条件 | 次元数 | 内容 |
| --- | ---: | --- |
| baseline | 96 | 既存の体幹基準座標・visibilityと、履歴の平均・標準偏差・差分 |
| relative_position | 110 | 既存96 + 相対位置7 + 有効性フラグ7 |
| relative_motion | 138 | 相対位置条件110 + 2種類の時間差それぞれの速度7・有効性フラグ7 |

追加する相対位置は、手首間の水平距離・垂直距離・直線距離、左右の手首の肩中心からのx・y位置。画像の縦横比を補正し、2次元の肩幅で正規化する。距離は非負、各手首の位置は符号付きで、画像の下方向がy正。

必要な肩・手首のvisibilityが0.5以下、座標が非有限、または肩幅が退化している場合、その値と有効性フラグを0にする。片手首だけが無効な場合、もう片方の肩中心に対する位置は利用できる。既存96次元の欠落処理は変えない。

速度は各相対位置の後方差分を実際の時間差で割った値。遅延フレーム数は `max(1, round(秒数 × fps))` とし、単位は肩幅/秒。手首間距離の速度が負なら接近を表す。両端の特徴量が有効な場合だけ計算し、履歴のない動画冒頭は無効とする。途中の欠落を補間せず、未来フレームも使わない。

### 学習・評価の分離

- 幕越し12動画をtake単位で外側3分割。外側学習動画だけで内側take分割を行い、phase macro F1が最大の設定を選ぶ。
- 分類器は既存の線形ridgeと、固定乱数の非線形特徴変換付きridge。履歴0.25／0.75秒、正則化0.01／0.1／1の12候補を各特徴量条件で比較する。標準化・クラス重みは各学習分割だけから算出し、未知phaseは学習・フレーム評価から除外する。
- 幕なし4動画は学習・設定選択に使わず、幕越し12動画で学習したモデルを適用する。ただし、これまでの実験で幕なしの失敗例も確認済みなので、完全な未使用データではない。
- actionは既存の外側予測を固定。後処理は表示保持0.75秒、観測された非RAMUNEで解除0.6秒、初回・再準備ともaction=RAMUNEかつFORMING/READYを0.3秒確認する。
- 基準の選択パラメータ、全16動画のphase予測、単独・連結の後処理結果を前回保存結果と照合し、完全一致を確認した。

学習設定の選択指標は比較のため従来のphase macro F1を維持する。一方、候補の採否には開栓区間の検出・誤出力を使う。短い注釈に表示を押し込めることは目的にせず、注釈を含む連続OPENEDの延長は正しい仕様として扱う。

連結は保存信号による状態機械のテストであり、骨格抽出・特徴量履歴・分類器を接続越しに動かした実動画評価ではない。同一信号のコピーを独立した正例として数えない。

## 採否と残る課題

相対位置条件は、検出数増加、両環境での誤出力非増加、2回目の見逃し非増加という今回の候補条件を満たす。速度条件は幕なしの検出減少と誤出力増加で不合格。判定理由はJSONにも保存した。

次に追跡する失敗はboth2幕越しのOPENED欠落と、ramune幕なしの観測不足。基準を相対位置条件に置き換えて次の比較を行う余地はあるが、今回の結果だけで本番に組み込まない。別撮影条件・連続実動画での再準備と誤出力の確認は別途必要である。
