# 現行実装への反映

- MediaPipeは `VIDEO` モードを既定とし、通常実行はHeavyモデルを使用します。
- 検出・存在・追跡confidenceは `0.50` を維持しています。
- 相対位置モデルによるラムネ判定は、`ramune.detector = "learned"` で選択できます。
- YOLO Poseの追跡・補間・平滑化は製品判定へ統合していません。

詳細な閾値と成立条件は [ジェスチャー仕様](gestures.md)、実行経路は
[構成と設定](architecture.md) と [Unity連携・OS別セットアップ・2カメラ](integration.md) を参照してください。

斜め映像ではHeavyへの変更で関節誤差と静止判定が改善しました。ラムネは縦横比の補正と
打ち水との優先順位を修正し、礼は部分的に隠れる鼻の可視度と頭部方向の条件を調整しました。
画面外に出た腰や、前屈中の追跡抜けは残っています。
測定値、採用しなかった変更、比較画像は[1007の評価記録](../shared/results/1007-comparison/REPORT.md)にあります。

## 注釈付き動画の評価

`gesture_detection/`から実行します。注釈側の`<セッション>/<カメラ>/timeline.json`と、
動画側の`<セッション>/<カメラ>.mp4`を対応させます。保存済みの絶対パスが別のPCを指していても、
`--videos`で指定した動画のSHA-256、解像度、フレーム数、FPSを検証してから評価します。

```bash
uv run python -m scripts.evaluate_timeline shared/annotations/1007 \
  --videos shared/videos/1007 --pose-model heavy \
  --output shared/results/1007-new-heavy
```

ライブと同じ`PoseAnalyzer`に全フレームを順番に渡します。入力時刻はフレーム番号/FPSです。
動画ごとに推定器・認識器を初期化し、2台の結果は別々に採点します。
フレーム数の違う録画を切り詰めたり、同じ番号のフレームを同期済みとみなして統合したりしません。
ライブのフレーム間引き、通信、Unityとの同時起動による遅延は、この評価には含みません。

モデルは`--pose-model lite|full|heavy`で比較できます。既定は実際の設定を使う`configured`です。
人物選択は既定で有効です。`--subject-selection off`は人物選択を無効にした診断、
`--profile multicam`は2カメラ用の認識ルールの単一視点評価に使います。

出力には`summary.json`、カメラごとの`frames.jsonl`、開始時点の注釈を保存した`annotations/`が含まれます。
モデル・ソースコード・注釈のハッシュ、設定、ライブラリの版も記録します。
中断後は同じコマンドに`--resume`を付けると、保存済み注釈を使って完了した動画を飛ばします。
設定やコードが変わった場合は再開を拒否します。通常の再実行には新しい出力先を指定してください。

### 指標の読み方

- 所作区間の検出数は、注釈区間中に1フレーム以上その所作を出した区間数です。準備から終了までの
  全区間を分母とするフレーム数も併記します。短い成功表示のラムネ・打ち水では、区間全体を検出する必要はありません。
- 注釈のない所作区間・フェーズ・イベントは未評価です。背景や誤検出と決めつけず、所作区間外の出力を別集計します。
- 注釈された`RAMUNE_OPEN`と`UCHIMIZU_RELEASE`は、既定で前後0.5秒以内の検出イベントと1対1で対応させます。
  重複検出は余分な検出として残します。時間許容は`--event-tolerance`で変更できます。
- 関節誤差は`marked`だけを対象に、元画像のピクセル座標で測ります。未注釈・`uncertain`・`absent`は座標誤差に含めません。
  平均・中央値は推定できた点について計算し、欠測数を併記します。`PCK@20px`は全`marked`点を分母とし、
  20px以内の点の割合を示します。欠測は失敗として数え、可視度の低い予測も除外しません。

### 追加注釈で再採点する

モデル間の比較には、同じ注釈を使います。推論済みなら再推論は不要です。

```bash
uv run python -m scripts.compare_pose_results \
  shared/results/1007-lite-baseline shared/results/1007-heavy-validated \
  --annotations shared/annotations/1007 \
  --output shared/results/1007-new-comparison --videos shared/videos/1007
```

`comparison.json`に全体・関節別・動画別の結果を保存します。`--videos`を付けると、
注釈点を緑、推定点を赤で重ねた画像も保存します。追加注釈の評価には同じフレーム順序・時刻の
キャッシュが必要です。モデル自体の再選択や認識処理の変更には、全フレームの再評価が必要です。

## 注意

評価結果は特定の撮影素材に対する研究記録であり、認識精度の保証ではありません。
1007はモデル選択と調整に使ったデータです。別の人物・撮影条件での独立した評価は未実施です。
顔が写る可能性のある画像、動画、注釈、JSON、生の推論出力は`shared`側で管理します。
