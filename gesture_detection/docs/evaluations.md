# 過去の評価

この索引は、過去の検証と現在の採否をまとめます。各 JSON は再集計用の生データであり、
それ自体を現在仕様や精度保証とはみなしません。正解区間がない評価の出力フレーム数は、
正解率、再現率、F1値ではありません。

## 現在の結論

- MediaPipe は `VIDEO` モードを既定とし、`IMAGE` は比較用に残す。
- 通常実行は MediaPipe Lite、検出・存在・追跡 confidence `0.50` を維持する。
- 幕越し映像では、Lite、Full、弱いぼかしのどれも4動作すべてを認識できなかった。
- ぼかし、縮小、CLAHE、中央マスクは全体適用しない。姿勢検出数が増えても、必要点や
  ジェスチャー判定の改善にはならず、誤検出が増える条件もあった。
- YOLO Pose の人物追跡・短時間補間・平滑化は試作品のままとし、製品判定へ統合しない。
  誤った骨格や長い欠落を解決できず、精度改善を確認できなかった。
- 次の評価では代表フレームまたは動作区間へ正解ラベルを付け、関節位置誤差と動作単位の
  指標でモデル・撮影条件を比較する。

## 夕涼み判定変更のリプレイ

同じVIDEOモードのランドマークを変更前後の分類器へ渡した結果です。フレーム単位の
正解ラベルがないため、状態の出力数であって認識精度ではありません。

| 動画 | 全フレーム | 変更前 | 変更後 |
| --- | ---: | ---: | ---: |
| sabaku_other_01.mp4 | 821 | 794 | 0 |
| kohara_relaxing_01 | 365 | 353 | 201 |

速度・固定位置からの変位の許容値を手動フィードバック後に `0.20 / 0.035` から
`0.30 / 0.05` へ緩めると、静止動画は132から201フレームへ増え、非対象動画は0のまま
でした。1秒の静止条件と、しきい値超過時の即時解除は維持しています。
[5.024秒の比較画像](relaxing-motion-release.jpg)では、動いている非対象動画から夕涼み表示が
消えています。オフライン再生のみの結果で、ライブカメラは未確認です。

## 打ち水と扇ぎの優先順位変更

同じVIDEOモードのランドマークで、打ち水準備中と成功直後の扇ぎ抑制を比較しました。

| 動画 | 全フレーム | 扇ぎ 変更前 → 変更後 | 打ち水 変更前 → 変更後 |
| --- | ---: | ---: | ---: |
| kohara_uchimizu_01 | 700 | 3 → 0 | 33 → 33 |
| kohara_fanning_01 | 1495 | 196 → 141 | 0 → 0 |

打ち水動画の一時的な扇ぎ出力を除去し、打ち水出力数は維持しました。一方、曖昧な準備・
復帰付近では本来の扇ぎ表示も一部抑制します。他動画で干渉がゼロになる保証はありません。
[3.563秒の比較画像](uchimizu-fanning-priority.jpg)では、打ち水の準備状態を維持して扇ぎ表示を
除去しています。この変更もライブカメラでは未確認です。
