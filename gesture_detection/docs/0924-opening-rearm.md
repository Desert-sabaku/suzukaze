# 0924 開栓判定の再許可・連続試行の追試

2026-09-24。現ブランチで実施。本番未統合。元の注釈は変更していない。

## 今回の判断

**前回の「手が離れたことを0.3秒確認する」候補は、2回目を妨げるため採用を保留する。** 同じ実動画の推論結果を2回連結し、後処理の状態を維持すると、1回目に成功した幕越し5本・幕なし1本のすべてで2回目が抑制された。再出現0回だけでは十分な評価ではなかった。

代案として、骨格が見えている間にactionがRAMUNE以外となる状態を0.6秒確認し、その後の準備確認を0.3秒にする固定条件を試した。元動画での成績を維持しつつ、連結実験の2回目を6/6で通した。ただし、この固定条件は既存データを見た追加探索であり、独立した未使用データでの性能保証ではない。

学習側だけで条件を選び直す比較も行った。その条件は2回目を通す一方、幕越しで再出現1回が残った。追加で調べた未注釈の連続動画では、全候補が最初の準備条件を満たせず表示を開始できなかった。**連続撮影による実証は未達**である。

## 1. 既存データの連結による後処理テスト

0924の各動画について、保存済みのaction・phase予測と骨格を2回並べ、時間を連続させて後処理を1回だけ起動した。注釈のフレーム番号は2本目の位置へ移動する。1本目と2本目の間で状態をリセットしない。

接続間隔は追加欠落なし・0.5秒の骨格欠落・2秒の骨格欠落を比較。挿入区間は未注釈として扱い、正解のNONEデータを人工的に増やさない。表示の入力にはNONE・骨格なしを渡す。骨格欠落だけでは解除しない仕様を維持した。

**これは実動画から得た信号の合成で、連続撮影の代わりではない。** Pose推論と分類器の履歴は各元動画で処理されたものを再利用するため、接続をまたいで連続しているのは後処理状態だけ。2回分を独立した新しい正例として数えず、元動画数と、1回目が通った例のうち2回目も通る割合を報告する。

| 条件 | 幕越し：元動画の注釈との重なり | 幕越し：再出現 | 連結時の2回目／1回目成功例 | 幕なし：元動画の注釈との重なり | 連結時の2回目／1回目成功例 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 前回：手の離れで解除 | 5/7 | 0 | 0/5 | 1/2 | 0/1 |
| 固定の追加探索条件 | 5/7 | 0 | 5/5 | 1/2 | 1/1 |
| 学習側のみで再選択 | 5/7 | 1 | 5/5 | 1/2 | 1/1 |

追加欠落0.5秒・2秒でも表の結果は同じ。元動画から残る幕越し2件（OPENEDなし1件・注釈より1フレーム遅い1件）と幕なし1件は、今回も改善していない。

### 前回条件が解除しなかった理由

前回条件は「actionがRAMUNE以外」「両肩・両手首のvisibilityが0.5超」「手首の横距離が0.8肩幅超」が0.3秒続くことを要求していた。0924のRAMUNE注釈がある9動画では、RAMUNE以外と予測された区間に、両手首が見え続ける0.3秒の区間がない。手を下ろすと手首が画角外・低visibilityになり、解除確認に進めない。

これは手が実際に離れていないという意味ではなく、現在の入力からその解除条件を観測できないという問題。欠落をそのまま「手を離した」とみなす変更はしていない。

### 比較した設定

- 前回：表示保持0.75秒、手の離れ＋非RAMUNEを0.3秒、準備を0.15秒。初回も準備必須。
- 固定の追加探索条件：表示保持0.75秒、観測された非RAMUNEを0.6秒、準備を0.3秒。手首の可視性・離れを解除の必須条件から外す。
- 学習側のみで再選択：解除方法context / hands、解除時間0.3 / 0.6 / 1.0秒、準備0.15 / 0.3 / 0.5秒の18候補。単独の区間F1と連結の区間F1の平均で選択。表示保持は前回の学習側選択0.75秒に固定。
- 準備は、骨格が取得され、actionがRAMUNE、phaseがFORMINGまたはREADYであること。解除・準備に正解注釈は使わない。

再選択では全分割でcontext・解除0.3秒・準備0.15秒が選ばれた。外側の幕越し評価ではramune3の再出現が1回残り、同じ動画を2回並べた信号では合計2回になる。学習側の限られた例では準備0.3秒の必要性を選びきれず、設定選択の不安定さが残る。

### 分割と探索上の注意

幕越しの外側take分割と幕なしの留保は前回と同じ。外側学習動画だけで選んだ基礎分類器設定を使い、内側では対象動画を除外して再学習した予測から、解除条件を選ぶ。別の外側分割で評価された予測を内側学習に流用しない。元の分類器の外側予測・注釈ハッシュは固定。

固定の追加探索条件は、このデータでの失敗を見て試した条件であり、自動再選択の評価と混同しない。合成の2回目は1回目と同一信号なので、新しい動作のばらつき・速い連続動作・人物交代は検証できない。

## 2. 別の連続動画の確認

既存の `shared/videos/kohara_ramune_01-おいしいかにかま.mov`（約30.8秒、924フレーム）に、手を戻して繰り返す動作が見られた。0924の学習動画には含めず、幕越し12動画で学習した固定モデルを適用した。中央マスク・Pose VIDEO・特徴量履歴・後処理は、この動画の先頭から末尾まで切らずに処理した。

この動画には今回のaction・phase正解注釈がない。画面上の動作が現在のRAMUNE仕様と一致するかも未確認なので、検出率は計算しない。

- 加工前のphase分類器はOPENEDを11区間出力。これは正解回数ではない。
- actionはRAMUNEを715フレーム出力する一方、phaseのREADYは15フレームのみ。FORMINGは0フレーム。
- actionがRAMUNEかつphaseがFORMING / READYとなるフレームは**0**。両分類器の準備判定が同時成立していない。
- 初回準備必須の前回条件・context解除の代案はいずれもOPENED出力なし。再解除の前に、最初の準備待ちから進めない。

したがって、連結テストの改善を「別人物・別画角の連続動画でも動く」とは扱わない。こちらのボトルネックは単純な再許可時間ではなく、入力条件の違いとaction / phaseの整合性にある。

## 次の対応

1. 前回の手首可視性を必須にした解除方式は、本番候補からいったん外す。固定の追加探索条件は比較用に残す。
2. 連続動画に現在の仕様でaction / phaseを付け、初回準備が成立しない理由を確認する。既存のkohara動画を使う場合は、期待する所作に合っているか確認してから正解区間を定める。
3. 同一試行の再出現だけでなく、正当な2回目の見逃しを評価指標として維持する。初回準備条件を単に外すだけでは、前回抑えた冒頭の誤出力が戻るため、別に比較する。
4. 実カメラへの組み込みは、連続撮影での再許可と入力条件間の整合性を確認してから行う。今回も本番コードは変更していない。
